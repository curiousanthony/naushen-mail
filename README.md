# Mailroom

A calm, keyboard-first desktop mail client for macOS — the ergonomics of Notion Mail (block-style composer with `/` menu,
Views, side-peek reading, `cmd+k`) for **Gmail** and **Outlook**, with no AI and no Notion dependency.

```bash
npm install
npm run dev          # develop
npm run dist         # build a macOS .dmg (see docs/install.md)
```

Start with the **Demo** account (Settings → Add account → Demo) to explore offline; connect real accounts after following
[`docs/06-provider-setup.md`](docs/06-provider-setup.md).
