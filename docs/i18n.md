# Internationalisation (i18n)

Runtime: `i18next` + `react-i18next`. Supported languages: see `src/shared/languages.ts`
(en, fr, es, de, pt-BR, ru, zh-CN, ja, hi). Arabic/Hebrew (right-to-left) are not supported yet: the layout uses
physical CSS properties and would need a dedicated RTL pass.

## Layout
`src/locales/<lng>/<namespace>.json`, one namespace per feature folder (`sidebar`, `threadlist`, `reader`, `compose`,
`commands`, `settings`, `rules`, …) plus `common` (shared words/dates) and `main` (main-process strings). English
(`en`) is the source of truth and the fallback for any missing key. Files are bundled eagerly (`import.meta.glob`).

## Conventions
- Component: `const { t } = useTranslation('threadlist')` then `t('empty.title')`. Outside React: `import i18n from '@/i18n'`,
  `i18n.t('common:date.today')`. Main process: `mt('notify.newMail', { count })` from `src/main/i18n.ts`.
- Keys are nested, lowerCamelCase, grouped by UI area: `toolbar.archive`, `empty.title`, `menu.moveTo`. Never build keys
  by concatenation and never concatenate translated fragments: use interpolation `{{name}}`.
- Plurals use i18next suffixes: `unread_one`, `unread_other` (+ `_few`/`_many` are added by translators where needed), called with `{ count }`.
- Rich text with markup: `<Trans i18nKey="…" components={{ b: <strong /> }} />`.
- Never translate: product name "Naushen Mail", provider names, keyboard-key glyphs, user data, email HTML.
- Dates/numbers: `Intl.*` with `currentLocale()` or date-fns with `dateLocale()` (`src/renderer/i18n/dateLocale.ts`). Never hard-code a locale.
- The language setting is `settings.language` (`'system'` | code). `applyLanguage()` also sets `<html lang>`.

## Adding a language
1. Add it to `LANGUAGES` in `src/shared/languages.ts` and to the date-fns map in `src/renderer/i18n/dateLocale.ts`.
2. Copy `src/locales/en/` to `src/locales/<code>/` and translate the values (keep keys, `{{placeholders}}`, and plural suffixes).
3. `npm test` (a test checks every locale has the same keys and placeholders as English).
